# IARD 2026 Talk Artifact

This directory is for files specific to the delivered IARD 2026 conference talk.

The talk was delivered June 11, 2026, 12:50-1:30 PM EDT, at Howard University in
Washington, DC, as the concluding talk of the June 8-11 IARD conference.

Use this directory for:

```text
slides/
    Keynote file, PDF export, and slide-specific media.

drafts/
    Any future revision of the talk text.

qa/
    Q&A specific to this delivered talk or its audience.

notes/
    Delivery aftermath, comments, and artifact-specific notes.

proceedings/
    IARD proceedings draft if developed from the talk.
```

The older `talk_project/` and root `drafts/` directories remain active for
continuity. Do not move files unless there is a specific benefit.
