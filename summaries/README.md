# Summaries

This directory is for source summaries organized by reuse context.

```text
general/
    Summaries useful across multiple artifacts and side quests.

artifact_specific/
    Summaries written for a particular talk, paper, or proceedings article.

side_quests/
    Summaries written for exploratory research lines.
```

The older `talk_project/reference_summaries/` directory remains active for
continuity. New summaries can be placed here when they are clearly part of the
larger multi-artifact structure.
